LastVix v18 — خطوات التفعيل (مرة واحدة)
=========================================

1) النشر (GitHub + Vercel)
   ارفع على نفس الريبو: index.html و sw.js و manifest.json و vercel.json (استبدل القديم)
   وأضف فولدر admin بكل ملفاته (index.html, sw.js, manifest.json, icon-192.png, icon-512.png).
   Vercel هيعيد النشر لوحده. لوحة الأدمن هتفتح على:  رابط-موقعك/admin/

2) Firebase (مشروع communication-ebba7)
   - Authentication > Sign-in method: فعّل Anonymous و Email/Password.
   - Authentication > Users > Add user:
       الإيميل:  ad123@lastvix.app   (بتكتب في اللوحة: AD123)
       الباسورد: 8 أحرف أو أكتر وقوي (مش AD123). انسخ الـ UID.
   - Realtime Database > Data: أضف  admins / <UID> = true
   - Realtime Database > Rules: امسح الموجود والصق محتوى database.rules.json ثم Publish.
     (قاعدة tenants في الملف هي الأساسية: أي مستخدم مسجّل يقرأ/يكتب جيمه. لو عندك قاعدة tenants أشد، انسخها مكانها.)

3) لوحة الأدمن  (/admin/)
   - ادخل AD123 + باسورد Firebase، ثبّتها على الموبايل (إضافة للشاشة الرئيسية).
   - تبويب «الأسعار»: حط رقم واتساب المطور، مدد الاشتراك وأسعارها، وسائل الدفع وأرقام المحافظ، أيام التجربة. اضغط حفظ.
   - تبويب «الطلبات»: بتقبل/ترفض طلبات الاشتراك والتجديد (القبول بيفعّل الاشتراك تلقائيًا ويبعت إشعار للمستخدم).
   - تبويب «الجيمات»: تمديد/تحديد تاريخ، إيقاف/تفعيل، حظر/فك حظر، إشعار خاص، إعادة التجربة، عرض بيانات الجيم.
   - تبويب «الحظر» و«إشعارات» (للجميع) و«إعدادات» (حفظ/استعادة نسخة احتياطية، تغيير الباسورد).

4) التطبيق نفسه (v18)
   - كل الجيمات بقت تجربة مجانية (الأيام من لوحة الأدمن، الافتراضي 7). بعد ما تخلص بتظهر صفحة الدفع + التواصل واتساب.
   - تاريخ نهاية اشتراك اللاعب = البداية + المدة − يوم (1 أكتوبر → 31 أكتوبر).
   - المالك المحلي (تبويب «مالك»): أول دخول بعد التحديث اكتب AD123 وباسورد جديد 10 أحرف فأكتر — بيتحفظ مشفّر (PBKDF2-SHA256) على الجهاز. AD123/AD123 القديم اتلغى.
   - باسوردات الحسابات القديمة بتتحوّل لتشفير تلقائيًا أول فتح بعد التحديث.
   - قسم «📸 صور المشتركين» في صفحة المشتركين: حفظ في المعرض / ZIP / واحدة واحدة.

ملاحظات أمان مهمة
   - الحماية الحقيقية للتراخيص والحظر والطلبات هي قواعد Firebase + حساب الأدمن، مش كود الموبايل.
   - التطبيق بيشتغل أوفلاين من الكاش؛ الحظر/التراخيص بتتطبق لما الجهاز يتصل. استخدم «أقصى مدة أوفلاين» في الإعدادات لإجبار الاتصال الدوري.
   - الإشعارات للجميع بتوصل لما التطبيق يتفتح أو يكون متصل (Push حقيقي والتطبيق مقفول محتاج سيرفر FCM).
